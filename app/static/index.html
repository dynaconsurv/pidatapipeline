Oracle ERP Cloud API Authentication & Integration Architecture:
  • OAuth 2.0 (Recommended for Production): Requests an access token from Oracle Identity Cloud Service (IDCS/IAM) using grant_type=client_credentials with your Client ID and Client Secret, then attaches Authorization: Bearer <access_token> to ERP REST calls.
  • Basic Authentication: Alternative for dev/test instances, sending Base64-encoded username:password in the Authorization: Basic ... header.
  • Pending Connection Setup: If you do not have the Oracle credentials yet, leave the ERP toggle OFF. The pipeline will pull AVEVA PI data safely and present "Pending connection setup" on the dashboard.
